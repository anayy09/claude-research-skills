# Evidence table templates

Keep study characteristics and results in separate tables. Combined tables
become unreadable and hide missing data.

---

## Table 1. Study characteristics

| Study (author, year) | Country / setting | Design | N analysed / enrolled | Population | Intervention or index test | Comparator | Outcomes reported | Funding | Risk of bias (tool, overall) |
|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | |

Columns that carry weight:

- **N analysed and enrolled separately.** The gap is attrition, which is a
  risk-of-bias domain. Reporting one number hides it.
- **Funding**, because it is a common source of the conflicts a reader will weigh.
- **Risk of bias in this table**, so quality sits beside the result rather than
  in a separate figure the reader may never reach.
- Write "not reported" rather than leaving a blank. A blank is ambiguous between
  not reported and not extracted, and only one of those is the study's fault.

---

## Table 2. Results

| Study | Outcome | Effect measure | Estimate (95% CI) | n analysed | Time point | Adjusted for | Notes |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

Record the effect exactly as the paper reports it, then record any conversion
separately with the formula used. Silent conversion cannot be audited, and
conversion errors are among the most common sources of a wrong pooled estimate.

## Table 3. Prediction model reviews (extraction per CHARMS)

| Study | Model type | Outcome predicted | Development or validation | Data source | Sample size / events per variable | Predictors (n, selection method) | Missing data handling | Discrimination (C-statistic, CI) | Calibration reported | External validation | Fairness assessed | PROBAST+AI overall |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | | | | |

The last four columns are usually where the finding is. Calibration absent,
external validation absent, and fairness unassessed are the norm rather than the
exception, and quantifying that across a literature is a publishable result in
itself.

---

## Table 4. Summary of findings (GRADE)

| Outcome | Studies (n) / participants (n) | Effect (95% CI) | Certainty | Reason for downgrade | Plain-language interpretation |
|---|---|---|---|---|---|
| | | | high / moderate / low / very low | | |

One row per outcome. This is the table most readers actually read. Draft it in
the first month: an outcome with no usable evidence is much cheaper to discover
early than after extraction is complete.
